# Dotfiles

> *Finally recreated my old terminal look after my old laptop died. Lesson learned: always keep backups! T_T*

## 📂 What's Inside?

* **`.zshrc`**: My custom Zsh configuration, aliases, and environment variables.
* **`.p10k.zsh`**: My Powerlevel10k theme configuration for that crisp, informative prompt.
